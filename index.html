Research overview

Efficient machine learning with rigorous empirical evaluation

I study how model efficiency can be improved without weakening the quality of the supporting evidence. My work examines predictive performance together with model size, memory use, runtime, convergence behavior, stability, and generalization.

My current methods include knowledge distillation, low-rank adaptation, quantization, controlled benchmarking, graph and hypergraph modeling, statistical testing, and reproducible experiment design.

Selected software project

Attention Is All You Need: Transformer implementation from first principles

This project reconstructs the original encoder-decoder Transformer in PyTorch. It covers token vocabularies, positional encoding, attention masks, multi-head attention, residual connections, normalization, feed-forward layers, training, and inference.
