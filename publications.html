Beyond Clean Accuracy: A Test-Blind Benchmark for Optimizer Reliability, Robustness, Calibration, and Computational Efficiency

Kazi Hafiz Md. Asad

Develops a research-engineered, test-blind benchmark for evaluating neural network optimization algorithms beyond conventional clean-test accuracy. Across 12 tabular classification datasets, the study systematically examines optimizer stability, robustness to feature corruption and label noise, hyperparameter sensitivity, predictive calibration, loss-landscape geometry, and computational efficiency. The benchmark is designed to reveal when apparent optimizer gains remain reliable under realistic perturbations, controlled experimental variation, and resource constraints.

Research Manuscript Final Stage Explainable Knowledge Distillation

ARGUS-KD: Attribution-Rationale Grounded Unified Student Distillation for Explainable Code Vulnerability Detection

Kazi Hafiz Md. Asad

Introduces ARGUS-KD, an explainable knowledge-distillation framework for code vulnerability detection that transfers not only predictive behavior but also the teacher model's underlying rationale and security evidence. Commit patch diffs are leveraged to construct ground-truth vulnerability rationales, while a compact student model is trained with a dedicated rationale head and a security concept bottleneck. The framework is designed to deliver efficient vulnerability predictions together with interpretable token-level explanations during inference without requiring additional explanation-time computation.
